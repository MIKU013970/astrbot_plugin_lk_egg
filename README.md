# 洛克王国 · 查精灵蛋

查精灵蛋图鉴、查孵化概率、查**炫彩花种市场**（颜色 / 粒子 / 价格）并订阅推送。

配合本机「蛋神助手」控制台使用：

| 功能 | 需要控制台？ |
|---|---|
| 查询 / 查蛋 / 蛋组 / 身高体重 | ❌ 纯本地 |
| 查蛋实时孵化概率 | ❌ 直连公开接口 |
| UID 查角色 | ❌ 直连洛克魔法书（需 API Key） |
| **花种查询 / 花种订阅推送** | ✅ 走控制台代理 |
| 查ID / 购买推送 / 新上架监控 | ✅ 走控制台 |

---

## 一、能查到什么

查一个精灵名，返回这张卡片：

| 项目 | 说明 |
|---|---|
| **区间数** | 这颗蛋刷身高体重时会落在几个区间里 |
| **蛋组** | 妖精组 / 拟人组 / 海洋组 … |
| **公母比例** | 雄性 % / 雌性 % |
| **进化链** | 从一阶段到最终形态的完整链路 |
| **身高 / 体重区间** | 官方图鉴给的范围 |
| **小块头 过线 / 极限** | 判小尺寸奖牌的阈值 |
| **大块头 过线 / 极限** | 判大尺寸奖牌的阈值 |
| **图鉴编号** | 游戏里的官方编号 |
| **蛋名** | 这颗蛋在游戏里叫什么 |
| **图标** | 精灵图 + 蛋图（有异色的还会多两张） |

多形态精灵（鸭吉吉、立方人、睡铃雪影娃娃这类）会把**每种规格**都列出来。

## 二、安装

1. AstrBot 插件目录里放好 `astrbot_plugin_lk_egg` 文件夹（或直接用 zip 上传）
2. 重启 AstrBot
3. 没有必填配置，装上就能用

依赖：AstrBot ≥ 4.0.0；出图需要 `pillow`（缺了也不会报错，会自动退回纯文字）；
`aiohttp`（查蛋概率和 UID 查角色要用，AstrBot 自带）。

## 三、怎么用

### 3.1 查精灵名字

```
查询 火花              完整图鉴卡
查蛋 火花              和「查询」完全一样
/查询火花              不加空格也行（前面带斜线）
查询 火神              进化链上任意名字都行
查询 鸭吉吉            多形态会列出每种规格
```

群聊需要带 `/` 前缀；私聊可以直接发名字（配置 `bare_name_private` 控制）。

### 3.2 用身高体重查（不知道是什么蛋时用）

三种写法都认：

```
0.32 2.12          身高按米、体重按千克（空格分隔）
34/3.617           身高按厘米、体重按千克（斜杠分隔）
34 3617            身高按厘米、整数体重按克算
```

会列出所有**身高体重区间能对上的蛋**，并按区间数量排序。

**并且会显示每种蛋的真实孵化概率：**

```
身高 27 cm · 体重 3.068 kg
可能孵出（2 种）：
1. 呼呼猪 · 69.8% · 区间 25
   蛋名 呼呼猪蛋 · 蛋组 动物组
2. 海盔虫 · 30.2% · 区间 18
   蛋名 海盔虫蛋 · 蛋组 海洋组 / 巨灵组
```

概率来自孵蛋预测接口（`cinene.cloud`，公开计算服务，不需要 key、不用登录）。
**低于 `identify_min_pct`（默认 1%）的品种会被隐藏**，避免把「理论上在区间内、
实际几乎不可能出」的品种列出来误导人；这项填 `0` 就是全都显示。

### 特殊精灵（默认不显示）

接口返回里除了「可能精灵」还有一段「特殊精灵」（活动 / 特殊途径获取的品种，
不属于普通蛋池）。**默认不显示**，只有打开 `identify_show_special` 才会一起列出来，
并且带上「特殊」标记：

```
1. 恶魔叮 · 47.5% · 区间 9
2. 优优 · 32.8% · 区间 13
3. 绿耳松鼠 · 19.7% · 区间 24
4. 新月鹭的蛋 · 43.4% · 特殊     ← 只有开启后才出现
```

本地图鉴里没有的品种会被跳过（不会拿模糊匹配凑名字）。

接口连不上时会自动退回本地区间匹配，并在说明里标注「可能含低概率品种」。

### 3.3 多形态精灵

同一只精灵有多个形态（比如兔系的不同规格）时，卡片会把每种形态的
身高 / 体重区间、过线值、极限值分别列出来。

### 3.4 按蛋组查全部精灵

```
查询 拟人组            列出拟人组全部精灵（一阶段名称 + 图鉴号）
查询 拟人              不带「组」也认
查询 海洋              海洋组同理
查询 组                看有哪些蛋组、各多少只
```

### 3.5 发图片还是发文字

默认发图片（排版整齐）。配置里关掉 `reply_as_image` 就发纯文字。
出图失败会自动退回文字，不用手动切。

### 3.6 图标（精灵图 / 蛋图）

卡片标题前会带图标，顺序固定：

```
普通一阶段 → 普通精灵蛋 → 异色一阶段 → 异色精灵蛋
```

异色那两个只在查精灵时出现；没有异色数据的精灵只出 2~3 个。

### 3.7 查游戏角色（UID）

```
UID 503671642          用游戏 UID 查角色资料
/UID503671642          不加空格也行
查UID 503671642        几种写法都认
```

能查到：角色等级、世界等级、性别、注册时间、在线状态、上次离线时间、
个性签名、图鉴收集数、时装羁绊、炫彩/异色精灵数、话题点、
家园名称 / 等级 / 房间等级 / 舒适度 / 好感 / 精灵数。

> **需要配置 `rocom_api_key`**（在 https://rocom.shallow.ink 申请）。
> 不填的话「UID」会提示未启用，其它功能完全不受影响。
> 查到的资料会缓存 6 小时，避免重复请求。

## 四、字段含义

| 字段 | 含义 |
|---|---|
| **区间数** | 这蛋的尺寸判定会被切成几个体重/身高区间 |
| **过线值** | 达到这个值才开始算「大块头」/「小块头」 |
| **极限值** | 这个尺寸能到的极限（判极限奖牌用） |
| **形态** | 精灵的不同规格（同一只蛋孵出来的差异） |
| **蛋名** | 游戏商城里这颗蛋显示的名字 |

```

**不用绑定游戏角色**，只要对方家园是公开的就能查。

返回：

———— 住民 10 只 ————
1. 星尘虫 【炫彩】 ♀ 急躁 1级 15cm 450g 100dB 昆虫组
4. 红绒十字 【异色,炫彩】 ♀ 大胆 40级 149cm 36.767kg -100dB 动物组/妖精组

声音 dB / 蛋组。还有生蛋配对和家具数量。

```

  · 电动长颈鹿的蛋
  · 卡波的蛋

### 3.9 炫彩花种市场

```

花种 罗隐              看这只精灵市面上的花种
花种 卡拉波斯          进化链上任意阶段名都行
花种 巨灵石            别的精灵同理
```

返回该精灵在花种市场的全部挂单：**颜色名 + 两个色值、粒子类型、价格、卖家、成团人数**：

```
🌸 罗隐 · 市面 3 个
1. 亮X暗 - 浅橙青 · 炫彩 · 命定 · 7星 · 4000 分
   色卡 #f1d397 / #3ed7d7
   粒子 方块
   卖家 玩家ede0 · 成团 0/2
   备注 海盐色的
2. 亮X暗 - 浅紫橙 · 炫彩 · 命定 · 7星 · 2000 分
   色卡 #dbbceb / #f9c924
   粒子 四角星
```

异色的挂单会显示成「异色」而不是「炫彩」。

### 3.9 花种订阅

```
花种订阅 颜色 浅橙青       订阅某个颜色（名字里包含这几个字就命中）
花种订阅 粒子 四角星       订阅某种粒子：四角星 / 方块 / 爱心
花种订阅 精灵 罗隐         订阅某只精灵的花种
花种订阅 / 花种订阅 列表   看当前订阅
花种订阅 删除 1           删掉第 1 条
花种订阅 清空             清空全部
```

有匹配订阅的新花种上架，会自动推送：

```
🌸 新花种上架
精灵：罗隐
外观：炫彩 · 命定
颜色：亮X暗 - 浅橙青  (#f1d397 / #3ed7d7)
粒子：方块
星级：7
价格：4000 分
卖家：玩家ede0（Z10025136）
成团：0/2

```

> 花种接口走 `/miniapp/api/grocery/flowers/*`，需要本机控制台在线
> （控制台已内置代理 `/api/grocery/flowers/*`）。
> 轮询频率由 `flower_poll_every` 控制（默认每 3 轮市场轮询扫一次 ≈ 60 秒）。

### 3.10 功能权限（在控制台配置）

**查ID / 花种 / 监控 / 推送** 这些功能可以限制只对指定的群或 QQ 开放。
配置在**控制台**里，不在插件配置页：

控制台 → 设置 → **权限** 页面：

| 项 | 说明 |
|---|---|
| 启用限制 | 关 = 谁都能用；开 = 按下面的名单控制 |
| 管理员 QQ | 无视限制，一行一个 |
| 额外授权的 QQ | 私聊可用，一行一个 |
| 允许使用的群号 | 群聊可用，一行一个 |
| 受限制的功能 | 勾选哪些功能要限制 |

受限制的功能有 7 类：

```
lookup_id   查ID / 查询ID
flower      花种查询 / 花种订阅
watch       新上架监控 / 蛋监控
push        蛋推送绑定/测试/状态/重置
roles       改绑记录 / 改名记录
marks       标 / 黑名单 / 白名单
```

**纯图鉴查询不受限制**：`查询 火花`、`查蛋 火花`、蛋组查询、身高体重查蛋，
所有人任何时候都能用。

**受保护对象**：在同一页面底部填 ZID / UID / 昵称（一行一个）。
有人查这些时，查询者只会看到「这个商家信息不对外提供」，
管理员会私聊收到「谁在哪个群查了什么」。

被拦时会回：

```
🔒 这个功能需要授权
「flower」只对指定的群/QQ 开放，或者找 1877811952 开通。
（纯图鉴查询不受限制：查询 火花 / 查蛋 火花 照常用）
```

> 权限配置存在控制台 `config.yaml` 的 `permissions` 段，
> 插件每次调用前会向控制台读一次（缓存 60 秒），改了配置一分钟内生效。

## 六、配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关，关掉后插件不响应任何指令 |
| `wake_prefix` | `/` | 指令前缀，想改成 `#`、`.` 都行 |
| `bare_name_private` | `true` | 私聊里允许直接发精灵名（群聊始终要前缀） |
| `show_body` | `false` | 查蛋时是否追加本体（成体）数据 |
| `reply_as_image` | `true` | 结果发图片；关掉强制发纯文字 |
| `card_theme` | 空 | 卡片配色，每行 `键=#RRGGBB`；可配 背景 卡片 边框 标题 正文 次要 强调 标签底 |
| `card_font_size` | `18` | 卡片正文字号，其它字号按它推导，范围 10~40 |
| `card_width` | `700` | 卡片宽度（像素），范围 320~1200 |
| `card_font_path` | 空 | 中文字体路径，留空自动找（Windows 微软雅黑 / Linux 文泉驿、思源黑体） |
| `admin_ids` | 空 | 管理员 QQ（逗号分隔），只有他们能用「诊断」/「诊断图标」 |
| `rocom_api_key` | 空 | **洛克魔法书 API Key**，填了才能用「UID」查角色资料；不填只是这个功能不可用 |
| `rocom_api_base` | 空 | 洛克魔法书接口地址，留空用默认 `https://wegame.shallow.ink` |
| `identify_use_remote` | `true` | 身高体重查蛋时用**实时孵化概率**；关掉退回本地区间匹配（会含低概率品种） |
| `identify_min_pct` | `1.0` | 低于这个百分比不显示；填 `0` 就全都显示 |
| `identify_timeout` | `10` | 概率接口超时（秒），超时退回本地区间匹配 |
| `identify_show_special` | `false` | 是否显示「特殊精灵」（活动/特殊途径品种） |
| `flower_enabled` | `true` | 开启花种订阅推送 |
| `flower_notify_target` | `bind` | 花种推送发到哪（写法同 `buy_notify_target`） |
| `flower_poll_every` | `3` | 每几轮市场轮询扫一次花种（3 ≈ 60 秒） |
| `identify_show_special` | `false` | **是否显示「特殊精灵」**（活动/特殊途径品种，不属于普通蛋池）；打开后列表里会标「特殊」 |

## 七、常见问题

| 问题 | 原因 / 解法 |
|---|---|
| 查不到某个精灵 | 传说精灵、活动限定这些官方图鉴没公开的品种查不到 |
| 名字打错了也能查到？ | 有模糊匹配和 897 条别名，错一两个字通常能中 |
| 出图失败，只收到文字 | 检查 `pillow` 装没装；`诊断` 指令能看到具体哪一步挂了 |
| 图片里中文变方块 | 系统缺中文字体，配 `card_font_path` 指到字体文件 |
| 想改卡片配色 | 配 `card_theme`，例如 `强调=#C25828` |
| 查了没反应 | 群聊要带 `/` 前缀；私聊要 `bare_name_private=true` |

## 开发说明

`main.py` 里 `_species_card()` 负责组数据、`card.py` 里 `render_species_card()`
负责画。想加字段就改 `_species_rows()` 返回的 `rows` 列表，一行一条
`(左列, 右列)`。

卡片配色 / 字号 / 宽度的配置最终都汇到 `_card_kwargs()`，改样式只动这一处。
