# 洛克王国 · 查精灵蛋

<div align="center">

**输入精灵名字或「身高/体重」，查这是什么蛋**

版本 `1.16.0`

</div>

---

## 一、能查到什么

输入精灵名字，或者直接发这颗蛋的身高体重，就能得到：

| 项目 | 说明 |
|---|---|
| **区间数** | 市集界面显示的「N区间」（数字越小，体重范围越窄） |
| **身高区间** | 这颗蛋孵出来的正常身高范围（cm） |
| **体重区间** | 这颗蛋孵出来的正常体重范围（kg） |
| **小块头** | 体重 ≤ 多少 → 出「小不点」，以及最小极限值 |
| **大块头** | 体重 ≥ 多少 → 出「大块头」，以及最大极限值 |
| **蛋组** | 这个精灵属于哪个蛋组 |
| **公母比例** | 雄性/雌性出生比例（如 雄性 80% / 雌性 20%） |
| **本体（成体）** | 孵化长大后的身高体重区间 + 大小块头过线值 |
| **进化链** | 完整进化顺序（任意一环的名字都能查） |
| **多形态** | 同一只精灵有多个体重规格时，全部列出 |
| **实时行情** | 查蛋时附带 大婉 / 小婉 / 大粗 / 小粗 的今日成交与最低积分 |

## 二、安装

把 `astrbot_plugin_lk_egg` 整个目录放进：

```
<AstrBot目录>\data\plugins\
```

然后在 AstrBot WebUI → 插件 → 重载。

依赖：

```
aiohttp >= 3.9.0
```

> 查精灵蛋是**纯离线**的，图鉴数据内置在 `ranges.json` 里，不需要任何外部服务或账号。

## 三、怎么用

### 3.1 查精灵名字

```
/查询 火花
/查蛋 火花            和「查询」完全一样
/查询火花             不加空格也行（前面带斜线）
查询 火花             带空格的话斜线可加可不加
```

进化链上**任意一个名字**都行（火花 → 焰火 → 火神 结果一样）。

> 没有空格、又看不出斜线的写法（比如直接发 `查询火花`），插件会先试着认一下精灵名：
> 认得出来就查，认不出来就当闲聊不理 —— 免得把聊天吃掉。
> （AstrBot 在派发前就把 `/` 剥掉了，插件里其实分不清你到底打没打斜线。）

**返回示例**

```
火花（火花蛋）图鉴 005 · 区间 16
蛋组：魔力组 / 巨灵组
公母比例：雄性 80% / 雌性 20%
进化链：火花 → 焰火 → 火神
身高区间：23~29 cm
体重区间：2.66~3.4 kg
小块头：过线 ≤2.675 kg · 极限 2.66 kg
大块头：过线 ≥3.385 kg · 极限 3.4 kg
大婉 55笔·338分·在售113
小婉 2笔·400分·在售27
大粗 5笔·399分·在售28
小粗 17笔·600分·在售13
```

> 最后 4 行是实时行情，不想看可以关掉，详见 [3.4 查蛋时的实时行情](#34-查蛋时的实时行情)。

**私聊可以不带 `/`**：私聊里直接发 `火花` 就行；群里必须带 `/`。

### 3.2 用身高体重查（不知道是什么蛋时用）

```
/34/3.617        身高 34cm、体重 3.617kg
/34 3.617        空格分隔也行
/0.34 3.617      身高按米写也行（游戏里显示的就是 0.34 这种）
/34/3617         身高 34cm、体重 3617g（整数默认按克算）
/查询 34/3.617   带指令写法也行
```

> 前面是**身高**，后面是**体重**，中间用斜线 `/`、空格、逗号、`x` 都认。
> **身高小于 4 的一律按「米」算**（游戏里那个 `0.32` 就是米），自动 ×100 换成厘米；
> 图鉴里最矮的蛋是 4cm，所以这个判断不会误伤。
> 体重带小数点或小于 100 时按 **kg** 算；纯整数且 ≥100 时按 **克** 算。

**返回示例**

```
身高 34 cm · 体重 3.617 kg
可能孵出（5 种）：
1. 电咩咩 · 区间 24 · 大块头（≥3.617kg）
   蛋名 电咩咩蛋 · 蛋组 动物组
   身高 25~34 cm · 体重 2.51~3.64 kg
2. 绿草精灵 · 区间 18 · 普通体型
   蛋名 绿草精灵蛋 · 蛋组 妖精组 / 拟人组
   身高 30~42 cm · 体重 3.255~4.12 kg
……
```

排序规则：**区间越窄越靠前**（范围越精确越可能是它），其次越靠区间中间越靠前。
同时会告诉你这颗蛋相对该精灵是**大块头 / 小块头 / 普通体型**。

### 3.4 查蛋时的实时行情

查到蛋之后，图鉴下面会跟 4 行市集行情（**只统计极限声线**）：

```
大婉 90笔·中位200分·低200分·在售77
小婉 15笔·中位240分·低199分·在售28
大粗 10笔·中位290分·低280分·在售13
小粗 6笔·中位266分·低288分·在售31
```

| 显示名 | 体型牌 | 声线牌 |
|---|---|---|
| **大婉** | 大块头 | 极限婉转声 |
| **小婉** | 小不点 | 极限婉转声 |
| **大粗** | 大块头 | 极限粗嗓门 |
| **小粗** | 小不点 | 极限粗嗓门 |

每行四个数依次是：**今日成交笔数 · 今日成交中位价 · 当前在售最低积分 · 当前在售件数**。
体型不区分普通/极限，两种都算进来。图鉴卡里这四项是右对齐的表格，还多了「中位价」一列。

- 数据来自市集「盯盘」，走控制台的 `/api/market/quote` —— **会员查这个不扣积分**
- 默认按蛋种缓存 **60 分钟**（`market_quote_cache_min`，设 `0` = 每次都查实时）
- 不想要就在配置里关掉 `market_quote_enabled`
- 控制台没起 / 超时 / 撞限流时，**只发图鉴正文、不显示行情**，不会卡住查蛋

### 3.5 发图片还是发文字

**v1.13.0 起，所有回复都发图片** —— 不只是查蛋，查ID、名单、监控列表、发码提示、
帮助菜单、报错提示，全都是同款卡片。出图失败会自动退回文字，不会发不出去。

```
/查询 治愈兔      → 图鉴卡（正文 + 大小头色块 + 行情表格）
/查ID Z10014514   → 商家卡（昵称 / 统计 / 货架明细）
/帮助             → 指令菜单卡（自动分栏对齐）
标记已删除         → 一句话也画成小卡片
```

卡片统一风格：标题、分隔线小节、两列对齐的说明、超长自动折行。
查蛋卡里的数字列右对齐，大小头用色块区分。

| 想改什么 | 改哪个配置 |
|---|---|
| 不要图片，强制发文字 | `reply_as_image` 设成 `false` |
| 配色 | `card_theme`，每行 `键=#RRGGBB`（可配 背景 卡片 边框 标题 正文 次要 强调 标签底） |
| 字号 | `card_font_size`（正文字号，标题 = +12、次要 = -3、数字 = +2） |
| 卡片宽度 | `card_width`（默认 700，范围 320~1200） |
| 中文字体 | `card_font_path`，留空自动找系统字体 |

出图耗时实测（含 PNG 编码）：

| 内容 | 耗时 | 体积 |
|---|---|---|
| 帮助菜单（37 行） | ~30 ms | ~55 KB |
| 查ID 商家卡 | ~2 ms | ~19 KB |
| 一句话短回复 | ~1 ms | ~3 KB |
| 查蛋图鉴卡 | ~30 ms | ~50 KB |

比行情接口本身的 400~600 毫秒小得多，基本感觉不到。发图比发文字多出来的时间在
QQ 侧上传图片，通常 0.1~0.5 秒。

> **帮助菜单和常用提示会在插件启动时预生成并缓存**，之后重复发送不再重画：
> 第一条 `/帮助` 约 5 ms，之后约 2 ms（改前是每次 62~63 ms）。
> 剩下的时间基本都花在 QQ 上传图片上，插件这边已经没什么可省的了。
>
> 环境里没装 Pillow、或者找不到中文字体时，会自动发文字，查蛋功能不受影响。
> 字体探测顺序：`card_font_path` → 插件目录里的 `font.ttf` → 系统字体。

### 3.6 查商家（查ID）

```
查ID Z10014514        助手ID
查ID z10014514        小写也行
查IDZ10014514         命令词和ID 粘一起也行
查 ID 10014514        命令词拆开写也行
查ID 咕咕              用平台昵称查
查ID 134961358         游戏ID（已建索引的才有）
```

> - **助手ID 大小写都认**，前面 `/` 可加可不加
> - **纯数字查不到时，会自动在前面补一个 `Z` 再查一次** —— 玩家报 ID 时经常忘了写 Z，
>   比如发 `10014514`，插件会按 `Z10014514` 再找一遍，查到会注明「你发的是纯数字」
> - 游戏ID 要先用他的助手ID 查过一次（插件记住映射），否则会提示「还没建索引」

### 3.7 最近成交（最近 / 历史）

精灵名后面加 `最近` 或 `历史`，查这个蛋种最近成交明细。
**按 4 种牌子分开列**（大婉 / 小婉 / 大粗 / 小粗），每种牌子各自按时间倒序、最多 10 笔：

```
查询 治愈兔 最近
/查询治愈兔历史
查蛋 治愈兔 最近
```

**返回示例**

```
治愈兔 · 最近成交（近 30 天 · 最新优先 · 每种牌子最多 10 笔）
【大婉】 今日 96 笔 · 中位 200 分 · 在售 74 · 最低在售 200 分
   1. 10-26 14:04   200 分
   2. 10-26 13:58   222 分
   ……
【小婉】 今日 16 笔 · 中位 240 分 · 在售 27 · 最低在售 199 分
   ……
【大粗】 今日 10 笔 · 中位 290 分 · 在售 12 · 最低在售 280 分
   ……
【小粗】 今日 7 笔 · 中位 266 分 · 在售 31 · 最低在售 250 分
   ……
```

> **为什么必须分开查**：接口每条成交只回 `{时间, 积分}`，**不带牌子标记**，
> 所以没法在一份结果里把「哪笔是大婉、哪笔是小粗」切开。只能带不同奖牌条件各查一次
> —— 一次查询要打 **4 发**。

- 走控制台的 `/api/market/recent`，底层是 `getPrivateMarketTrend`
  （小程序里「最近 10 笔成交」那一栏）。查蛋行情用的那个接口只给按天/四小时聚合的
  `series`，拿不到逐笔，所以只能换这个。
- **会员免费**（实测连打多轮，积分 3019.5 → 3019.5）；但它和查蛋行情共用
  私享 20 次/分钟额度，一次查询占 4 个额度，所以按蛋种缓存 **10 分钟**
- 四种牌子之外的成交（比如普通声线）不在这个列表里

### 3.8 图标（精灵图 / 蛋图）

卡片里带图了：

| 场景 | 放什么图 |
|---|---|
| **查精灵** | 名字**前面**放「一阶段精灵图」+「蛋图」两张 |
| **身高体重查蛋** | 每条候选结果：名字在左栏，**一阶段图塞在名字下面**那块空白里，右边紧跟 `区间 · 体型`、`蛋名 · 蛋组 · 公母`、`身高 · 体重` |
| **最近成交 / 行情** | 名字前面只放蛋图 |
| **查 ID** | 货架做成图标格：**图下三行 —— 蛋名 / 价格 / 奖牌简写**（`大·婉` / `小·粗` / `无牌`）。**名字、价格、奖牌三样都一样才合并**成一格并标 `×N`；同种但价格不同、或价格相同但奖牌不同，就各占一格 |

图源是 wiki 资源站：

```
蛋图     https://wegame.shallow.ink/api/v1/resources/wiki/assets/items/bag/<id>.png
精灵图   https://wegame.shallow.ink/api/v1/resources/wiki/assets/pets/<id>/small.png
```

插件里带了一份缩好的副本（`icons/`，404 张 96×96 PNG，共约 0.9 MB），
**装好就能用，不用联网**。精灵图取的是**进化链的第一阶段**
（`petBaseData` 里 `chainMembers[0]`），所以查火神也会显示火花的图。

> 图标缺失、Pillow 没装、或者打包时漏了 `icons/` 目录时，卡片会自然退化成
> 纯文字卡片，不会报错。

**查 ID 的卡片**还会带：

- **平台头像**：放在名字前面。图源是 `merchant.avatarUrl`，走控制台 `/api/avatar?u=`
  代理下载（插件直连云端头像是会失败的），本地缓存 24 小时
- **绑定的游戏 UID**：一个助手ID 可以绑多个游戏角色，全列出来，格式 `游戏UID · 游戏内昵称`
  （来自 `getEggMarketMerchantHome` 的 `roles`）
- **称号**（`merchant.title`，比如「破壳新人」）和**家园等级**（`home.roomLevel`）
- 助手ID 只在表格里出现一次（以前标题底下还挂一遍，重复了）

> ⚠️ 平台接口**没有角色等级** —— `roles` 里只有 `gameId` 和 `name` 两个字段，
> 实测 `getEggMarketMerchantHome` 的原始返回也是这样。能拿到的「等级」只有**家园等级**，
> 卡片上就是按这个标的。

**货架合并规则举例**（同一个玩家的货架）：

```
雪绒鸟蛋 300 分 大块头·婉转声   ┐
雪绒鸟蛋 300 分 大块头·婉转声   ┘ → 一格「300 分 / 大·婉 ×2」

雪绒鸟蛋 120 分 大块头·婉转声     → 一格「120 分 / 大·婉」   （价格不同）
雪绒鸟蛋 300 分 小不点·婉转声     → 一格「300 分 / 小·婉」   （奖牌不同）
火花蛋    88 分 无牌             → 一格「88 分 / 无牌」
```

同种精灵排在相邻位置，种内按价格升序。

## 四、字段含义

| 字段 | 含义 |
|---|---|
| `区间 N` | 市集界面显示的「N区间」，官方 weightBinCount |
| `身高区间` | 该蛋的正常身高范围 |
| `体重区间` | 该蛋的正常体重范围 |
| `小块头过线` | 体重 **≤** 这个值 → 出「小不点」 |
| `大块头过线` | 体重 **≥** 这个值 → 出「大块头」 |
| `极限值` | 区间两端（最小 / 最大可能值） |
| `蛋组` | 该精灵所属蛋组 |
| `进化链` | 完整进化顺序 |

**过线值算法**（与游戏内判定一致）：

```
小块头上限 = round(区间下限 × 98% + 区间上限 × 2%)
大块头下限 = round(区间下限 × 2%  + 区间上限 × 98%)
区间数     = floor(区间上限) − 大块头下限 + 1
```

## 六、配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `wake_prefix` | `/` | 指令前缀，想改成 `#`、`.` 都行 |
| `bare_name_private` | `true` | 私聊里允许直接发精灵名（不带前缀） |
| `show_body` | `false` | 查蛋时是否追加本体（成体）数据 |
| `enabled` | `true` | 是否启用插件 |
| `code_groups` | 空 | **发码目标群号**，多个用逗号隔开（随机挑一个群发） |
| `code_pool` | 空 | 备选兑换码，一行一个（发指令不带码时随机取） |
| `market_quote_enabled` | `true` | 查蛋时是否附带实时行情 |
| `market_quote_cache_min` | `60` | 行情缓存分钟数，同一只蛋这段时间内复用缓存；`0` = 每次都查实时 |
| `market_quote_timeout` | `6` | 行情请求超时（秒），超时就只发图鉴 |
| `reply_as_image` | `true` | 查蛋结果发图片；关掉就强制发纯文字（出图失败也会自动退回文字） |
| `card_theme` | 空 | 卡片配色，每行 `键=#RRGGBB`；可配 背景 卡片 边框 标题 正文 次要 强调 标签底 |
| `card_font_size` | `18` | 卡片正文字号，其它字号按它推导（标题 +12、次要 -3、数字 +2），范围 10~40 |
| `card_width` | `700` | 卡片宽度（像素），范围 320~1200 |
| `card_font_path` | 空 | 中文字体文件路径，留空自动找 |

> 群聊始终需要前缀；私聊默认可以裸发。

## 七、常见问题

| 现象 | 原因 |
|---|---|
| 群里发精灵名没反应 | 群里必须带 `/`：`/查询 火花` |
| 私聊发名字没反应 | `bare_name_private` 被关了 |
| 查不到某精灵 | 换成进化链上的其它名字试试；或数据里没这只 |
| `查id` 小写没反应 | v1.12.1 起大小写都认；老版本命令词必须写 `查ID` |
| `34/3.617` 没反应 | 确认是「身高 + 体重」两个数，中间用 `/`、空格、逗号、`x` 都行 |
| `0.32 2.12` 查不出来 | 老版本只认厘米 + 斜线。本版起空格/逗号/`x` 都认，且**身高小于 4 自动按米处理** |
| 身高体重匹配出一堆 | 正常，区间重叠的精灵本来就多，从上往下看即可 |
| 怎么判断大小头 | 看「小块头过线 / 大块头过线」，对照这颗蛋的实际体重 |
| 查蛋没有那 4 行行情 | 控制台没启动、请求超时、或 `market_quote_enabled` 被关了（看 AstrBot 日志里 `[查蛋行情]` 那行） |
| 发出来是文字不是图片 | `reply_as_image` 被关了，或环境里没 Pillow / 没中文字体（看日志里 `[出图]` 那行） |
| 图片太小/太大、字挤 | 调 `card_width`（宽）和 `card_font_size`（字号） |
| 图片里中文是方块 | 系统没有中文字体，用 `card_font_path` 指定一个 ttf / ttc |
| `查询火花` 没反应 | 只能是认得出来的精灵名；写成 `/查询火花` 或 `查询 火花` 更稳 |
| 最近成交查不到 | 控制台没起、或这名字图鉴里没有；先 `查询 名字` 确认一下 |
| 公母比例显示「未知」 | 官方数据里这只精灵缺 `genderRatio`（高低体重那些都有，唯独没性别）。告诉我实际比例，加到插件里的 `GENDER_OVERRIDE` 表就行 |

## 十、发码到群

把兑换码随机发到**设置里指定的群**。

### 先在配置里填群号

```
code_groups: 123456789,987654321     ← 群号，多个用逗号隔开
code_pool:                            ← 可选：备选码池，一行一个
  EGG-AAAA-1111
  EGG-BBBB-2222
```

### 指令

```
/发码                      从最早的 10 个可领码里随机发 1 个
/发码 EGG-XXXX-XXXX        直接发这个码
/输入兑换码 EGG-XXXX       同上（两个名字都能用）
/发码记录                  看发码记录（仅管理员）
/发码记录 清空             清空记录（仅管理员）
```

> 发码记录默认只有管理员能看：在配置里把 QQ 号填进 `admin_ids`（逗号分隔）。
> 没配 `admin_ids` 时，只有私聊里能查记录。

### 实测返回

```
已发放：EGG-TEST-0001
发到群：123456789（从 2 个群里随机选）
```

> 群号必须是**机器人已经在群里的**群，否则发送会失败并返回提示。

### 自动补货（可选，默认关闭）

如果当天要发的码不够，可以让插件去市集买便宜的蛋补上。

**打开方式**：配置里把 `auto_buy_enabled` 改成 `true`（**默认 false，打开会花积分**）

| 配置 | 默认 | 说明 |
|---|---|---|
| `auto_buy_count` | 10 | 每次最多补几个 |
| `auto_buy_max_points` | 10 | 只买 ≤10 分的挂单 |
| `auto_buy_keyword` | 神奇蛋 | 只买名字含这个字的 |

**执行流程**

```
每日发码时发现码不够
   ↓
在 10 分档买
   ↓ 没买够 → 让控制台刷新一次市集 → 同价位再买一次
   ↓ 还不够 → 加 auto_buy_step（默认 +1 分）→ 重复上面的步骤
   ↓
一直加到 auto_buy_ceiling_points（默认 13 分）为止
   ↓
重新拉取兑换码 → 继续发
```

每一档都是「名字含关键字 + 非密码房 + 分数 ≤ 该档价」，按价格从低到高买。

控制台接口支持预览（`confirm=false` 只列候选不下单），日志里每条购买都会记录。

> ⚠️ 这个开关是**真花钱**的，默认关闭。先确认 `auto_buy_max_points` 和每日数量再打开。
