# 洛克王国 · 查精灵蛋

<div align="center">

**输入精灵名字或「身高/体重」，查这是什么蛋**

版本 `1.9.1`

</div>

---

## 一、能查到什么

输入精灵名字，或者直接发这颗蛋的身高体重，就能得到：

| 项目 | 说明 |
|---|---|
| **区间数** | 市集界面显示的「N区间」（数字越小，体重范围越窄） |
| **身高区间** | 这颗蛋孵出来的正常身高范围（cm） |
| **体重区间** | 这颗蛋孵出来的正常体重范围（kg） |
| **小块头** | 体重 ≤ 多少 → 出「小不点」，以及最小极限值 |
| **大块头** | 体重 ≥ 多少 → 出「大块头」，以及最大极限值 |
| **蛋组** | 这个精灵属于哪个蛋组 |
| **公母比例** | 雄性/雌性出生比例（如 雄性 80% / 雌性 20%） |
| **本体（成体）** | 孵化长大后的身高体重区间 + 大小块头过线值 |
| **进化链** | 完整进化顺序（任意一环的名字都能查） |
| **多形态** | 同一只精灵有多个体重规格时，全部列出 |

---

## 二、安装

把 `astrbot_plugin_lk_egg` 整个目录放进：

```
<AstrBot目录>\data\plugins\
```

然后在 AstrBot WebUI → 插件 → 重载。

依赖：

```
aiohttp >= 3.9.0
```

> 查精灵蛋是**纯离线**的，图鉴数据内置在 `ranges.json` 里，不需要任何外部服务或账号。

## 三、怎么用

### 3.1 查精灵名字

```
/查询 火花
/查询 火神
/查询 焰火
```

进化链上**任意一个名字**都行（火花 → 焰火 → 火神 结果一样）。

**返回示例**

```
火花（火花蛋）图鉴 005 · 区间 16
蛋组：魔力组 / 巨灵组
公母比例：雄性 80% / 雌性 20%
进化链：火花 → 焰火 → 火神
身高区间：23~29 cm
体重区间：2.66~3.4 kg
小块头：过线 ≤2.675 kg · 极限 2.66 kg
大块头：过线 ≥3.385 kg · 极限 3.4 kg
```

**私聊可以不带 `/`**：私聊里直接发 `火花` 就行；群里必须带 `/`。

---

### 3.2 用身高体重查（不知道是什么蛋时用）

```
/34/3.617        身高 34cm、体重 3.617kg
/34/3617         身高 34cm、体重 3617g（整数默认按克算）
/查询 34/3.617   带指令写法也行
```

> 斜线前面是**身高**，后面是**体重**。
> 体重带小数点或小于 100 时按 **kg** 算；纯整数且 ≥100 时按 **克** 算。

**返回示例**

```
身高 34 cm · 体重 3.617 kg
可能孵出（5 种）：
1. 电咩咩 · 区间 24 · 大块头（≥3.617kg）
   蛋名 电咩咩蛋 · 蛋组 动物组
   身高 25~34 cm · 体重 2.51~3.64 kg
2. 绿草精灵 · 区间 18 · 普通体型
   蛋名 绿草精灵蛋 · 蛋组 妖精组 / 拟人组
   身高 30~42 cm · 体重 3.255~4.12 kg
……
```

排序规则：**区间越窄越靠前**（范围越精确越可能是它），其次越靠区间中间越靠前。
同时会告诉你这颗蛋相对该精灵是**大块头 / 小块头 / 普通体型**。

---

### 3.3 多形态精灵

同一只精灵在官方图鉴里有多个体重规格时会全部列出：

```
/查询 鸭吉吉
```

```
鸭吉吉（鸭吉吉蛋）图鉴 011 · 6 种形态
蛋组：天空组
公母比例：雄性 50% / 雌性 50%
进化链：鸭吉吉
1. 鸭吉吉（蓬松的样子） · 区间 40 · 28~39 cm · 5.11~7.04 kg
   小块头 ≤5.149 kg · 大块头 ≥7.001 kg · 雄性 50% / 雌性 50%
2. 鸭吉吉（紧实的样子） · 区间 27 · 28~39 cm · 1.96~3.28 kg
   ……
6. 鸭吉吉（燃了鸭） · 区间 40 · 29~41 cm · 5.331~7.28 kg
```

## 四、字段含义

| 字段 | 含义 |
|---|---|
| `区间 N` | 市集界面显示的「N区间」，官方 weightBinCount |
| `身高区间` | 该蛋的正常身高范围 |
| `体重区间` | 该蛋的正常体重范围 |
| `小块头过线` | 体重 **≤** 这个值 → 出「小不点」 |
| `大块头过线` | 体重 **≥** 这个值 → 出「大块头」 |
| `极限值` | 区间两端（最小 / 最大可能值） |
| `蛋组` | 该精灵所属蛋组 |
| `进化链` | 完整进化顺序 |

**过线值算法**（与游戏内判定一致）：

```
小块头上限 = round(区间下限 × 98% + 区间上限 × 2%)
大块头下限 = round(区间下限 × 2%  + 区间上限 × 98%)
区间数     = floor(区间上限) − 大块头下限 + 1
```

## 六、配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `wake_prefix` | `/` | 指令前缀，想改成 `#`、`.` 都行 |
| `bare_name_private` | `true` | 私聊里允许直接发精灵名（不带前缀） |
| `show_body` | `false` | 查蛋时是否追加本体（成体）数据 |
| `enabled` | `true` | 是否启用插件 |
| `code_groups` | 空 | **发码目标群号**，多个用逗号隔开（随机挑一个群发） |
| `code_pool` | 空 | 备选兑换码，一行一个（发指令不带码时随机取） |

> 群聊始终需要前缀；私聊默认可以裸发。

## 七、常见问题

| 现象 | 原因 |
|---|---|
| 群里发精灵名没反应 | 群里必须带 `/`：`/查询 火花` |
| 私聊发名字没反应 | `bare_name_private` 被关了 |
| 查不到某精灵 | 换成进化链上的其它名字试试；或数据里没这只 |
| `34/3.617` 没反应 | 格式要 `身高/体重`，中间是斜线 |
| 身高体重匹配出一堆 | 正常，区间重叠的精灵本来就多，从上往下看即可 |
| 怎么判断大小头 | 看「小块头过线 / 大块头过线」，对照这颗蛋的实际体重 |

## 十、发码到群

把兑换码随机发到**设置里指定的群**。

### 先在配置里填群号

```
code_groups: 123456789,987654321     ← 群号，多个用逗号隔开
code_pool:                            ← 可选：备选码池，一行一个
  EGG-AAAA-1111
  EGG-BBBB-2222
```

### 指令

```
/发码 EGG-XXXX-XXXX        把指定的码随机发到某个群
/输入兑换码 EGG-XXXX       同上（两个名字都能用）
/发码                      从备选池随机取一个码发出去
```

### 实测返回

```
已发放：EGG-TEST-0001
发到群：123456789（从 2 个群里随机选）
```

> 群号必须是**机器人已经在群里的**群，否则发送会失败并返回提示。

### 自动补货（可选，默认关闭）

如果当天要发的码不够，可以让插件去市集买便宜的蛋补上。

**打开方式**：配置里把 `auto_buy_enabled` 改成 `true`（**默认 false，打开会花积分**）

| 配置 | 默认 | 说明 |
|---|---|---|
| `auto_buy_count` | 10 | 每次最多补几个 |
| `auto_buy_max_points` | 10 | 只买 ≤10 分的挂单 |
| `auto_buy_keyword` | 神奇蛋 | 只买名字含这个字的 |

**执行流程**

```
每日发码时发现码不够
   ↓
在 10 分档买
   ↓ 没买够 → 让控制台刷新一次市集 → 同价位再买一次
   ↓ 还不够 → 加 auto_buy_step（默认 +1 分）→ 重复上面的步骤
   ↓
一直加到 auto_buy_ceiling_points（默认 13 分）为止
   ↓
重新拉取兑换码 → 继续发
```

每一档都是「名字含关键字 + 非密码房 + 分数 ≤ 该档价」，按价格从低到高买。

控制台接口支持预览（`confirm=false` 只列候选不下单），日志里每条购买都会记录。

> ⚠️ 这个开关是**真花钱**的，默认关闭。先确认 `auto_buy_max_points` 和每日数量再打开。
